‌What is this exactly?‌


It's a fully functional retro-style CCTV observation console built with Three.js and vanilla JS, set in a two-story neon-lit shopping mall atrium. It looks like a serious security room out of a heist movie, but it's actually just a chill sandbox waiting for your ideas. 🏬✨


How to mess around with it


Click any camera feed on the 6-screen grid to zoom it full screen, scroll to zoom in/out

Select a patrol robot, use WASD to drive around, arrow keys to move the camera gimbal, click POV to jump into first-person view

Deploy a drone: WASD to fly around, Space to climb, Shift to descend, check your altitude on the HUD

Hit ESC to exit any camera view, click the CAPUTRE button anytime to save a screenshot

Every screen has live REC indicators, timestamps, and that wobbly CRT glow security UI vibe


What's already built in


6 pre-placed CCTV cameras covering the whole mall with smooth camera tweening

Controllable ground patrol robot with first-person POV, zoom, and collision detection

Flyable drone with altitude control, adjustable zoom, and full 3D movement

Procedurally animated escalators, glowing neon accent lighting, dynamic 3D shadows

Drag-and-drop style on-screen mobile controls for robot/drone that work on phones

One-click screenshot save with flash effect

Fully responsive layout that works on desktop, tablets, and phones

Zero external assets besides the Three.js CDN — all geometry and effects are generated in code
